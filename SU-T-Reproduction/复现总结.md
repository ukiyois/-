# SU-T 本地复现总结

## 结论

**在用户确定的范围内，本地复现与方法核验已完成，结论足够用于核对实现和模块贡献。** 这项工作没有重新训练模型，也没有向官方平台提交结果。MFT25 测试标注不可见，因此没有复现论文隐藏测试集分数；本地所有指标均来自作者训练视频提供的 `val_half`，不能与论文测试集数字直接比较。

## 做了什么

1. 用作者发布的检测器和 Re-ID 权重运行作者评测入口，不重训模型。
2. 在作者 MFT25 训练视频的 `val_half` 上完整运行 8 段序列、16,035 帧、132,057 个 GT 目标，保留逐帧预测、运行日志、配置、权重哈希和运行元数据。
3. 对检测器只推理一次，缓存 148,250 个 NMS 后检测框；所有跟踪变体读取同一批检测框，并用 TrackEval 1.3.0 评分。
4. 通过同检测、同帧、同评测条件比较 KF+IoU、UKF+IoU、KF+FishIoU、UKF+FishIoU、UKF+FishIoU+ReID，并加入可兼容的 ByteTrack、OC-SORT 作为系统级参考。

数据拆分见 [`data/dataset.md`](data/dataset.md) 与 [`data/dataset_manifest.json`](data/dataset_manifest.json)；完整 A03 运行记录见 [`logs/sut_reid_valhalf_attempt03_console.log`](logs/sut_reid_valhalf_attempt03_console.log)；A05 结果和解释见 [`固定检测消融_A05报告.md`](固定检测消融_A05报告.md)。

## A05：固定检测消融

指标为 pooled TrackEval 百分比；同一行各项使用同检测输入、同评分配置。

| 跟踪配置 | HOTA | IDF1 | IDSW |
|---|---:|---:|---:|
| KF + IoU | 49.5903 | 54.0293 | 451 |
| UKF + IoU | 49.9187 | 54.6406 | 452 |
| KF + FishIoU | 48.7789 | 54.2346 | 505 |
| UKF + FishIoU | 48.9075 | 53.8592 | 509 |
| UKF + FishIoU + Re-ID | 50.1162 | 57.0874 | 392 |
| ByteTrack | **50.8557** | **58.3894** | **331** |
| OC-SORT | 48.7990 | 53.7375 | 404 |

### 本地结果说明

- UKF 在 IoU 条件下相对 KF：HOTA +0.3284、IDF1 +0.6113，IDSW 多 1 次，提升较小。
- FishIoU 在 KF/UKF 下的 pooled HOTA 分别比对应 IoU 条件低 0.8114 / 1.0112 个百分点；逐视频方向不一，不能概括为本地整体提升。
- 在 UKF+FishIoU 上加入 Re-ID：HOTA +1.2087、IDF1 +3.2282、AssA +1.9017 个百分点，IDSW 减少 117 次；这批视频中的收益主要体现在身份关联，且不同序列并不一致。
- ByteTrack 在相同检测框下的 HOTA 和 IDF1 高于 SU-T+ReID，IDSW 更少。它是系统级对照，不是针对 SU-T 某一个模块的消融。
- A03 作者入口结果与 A05 固定缓存的 SU-T+ReID 结果高度接近：HOTA 相差 −0.0737、IDF1 −0.1861、MOTA −0.0174 个百分点、IDSW 多 1 次，支持缓存/回放链路与作者入口对齐。

## 应如何表述完成度

可以表述为：**完成了基于作者公开权重的本地验证复现，并完成同检测输入下的组件消融核验。**

不能表述为“完整复现了论文测试成绩”或“本地验证证明 SU-T 在所有数据上优于基线”。边界如下：

- `val_half` 是训练视频的时间后半段，不是独立测试集；公开 checkpoint 是否用过这些帧，无法独立确认。
- 没有训练 detector、Re-ID 或 tracker；没有计算训练流程的复现性。
- 没有测试集标注，也没有官方排行榜分数；论文测试集指标不能从本地 GT 重算。
- 本地 ByteTrack 等对照共享检测框，但跟踪器内部轨迹管理不同，适用于系统级参考，不用于单模块因果归因。

因此，在原先约定的“不训练、不提交，只在作者提供的 `val_half` 上验证实现与消融”范围内，结果已完成且档案齐全；如果要求严格复现论文表格，还需要官方隐藏测试评测权限/标注以及原训练条件。
